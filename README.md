One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance — a washing machine that ransoms your socks back, one a week, in exchange for softer detergent.

> My washing machine returns one sock a week with a ransom note demanding softer detergent.

## Run it

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (89 characters, one sentence, UTF-8). Set `OUTPUT_DIR` to write elsewhere for local testing.
